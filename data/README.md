## `geodesy-fixture.json`

`claw.env.geodesy`(정본)와 `web/js/lib/geo.js`(사본)가 같은 수를 내는지 대조하는 고정점이다.
웹은 프레임마다 NED→타일 좌표를 계산해야 해서 서버 왕복이 불가능하고, 그래서 같은 식이 두
언어로 존재한다. **양쪽 테스트가 이 파일을 같이 읽으므로 한쪽만 고치면 반대쪽이 빨개진다.**

값을 고칠 일이 생기면 **엔진에서 재생성**한다. `h_ref`가 0인 블록만 두면 그 인자가
사각지대가 되므로(웹에서 `+ hRef`를 지워도 테스트가 다 통과했던 전력이 있다) 0이 아닌
블록을 함께 둔다.

## `geo/` — 지형 자산 (커밋 대상 아님)

```
data/geo/
  raw/                      내려받은 원본 타일 캐시
  site-terrain-v1.bin       구운 지형 팩 (약 2.2 MB)
```

**왜 커밋하지 않나.** 코드(1 MB 미만)·의존성(수백 MB)과 변경 빈도가 또 다르다 — 지형은
**세 번째 꾸러미**이고, `docs/deploy-airgap.md`가 코드와 의존성을 가른 것과 같은 사유다.
재생성이 가능하므로 리포에 실을 이유가 없다.

### 다시 굽기

```bash
python3 scripts/terrain/build_terrain.py \
    --origin-lat 34.601303 --origin-lon 127.212067 \
    --tier core:radius=12000,step=30 --tier outer:radius=30000,step=90 \
    --out data/geo/site-terrain-v1.bin
```

원점은 고흥 국가종합비행성능시험장 활주로의 **남단 임계**이고, 항공영상에서 측정한
값이다 — 방법·검산·불확실도는 `goheung-runway.json`에 있다. 팩은 gitignore 대상이라
이 명령이 재생성의 유일한 근거다: **원점을 바꾸면 여기와 goheung-runway.json,
`web/js/views/sim.js`의 기본값이 함께 움직여야 한다.**

자산이 없으면 가상환경 탭은 **지형 없이** 돌고(기준면 평면 + 활주로 + 궤적), 캡션이 무엇이
없어서 없는지 말한다. 서버는 이 폴더를 읽기만 하며 **바깥으로 나가지 않는다**.

### 자료 출처

현재 팩은 **AWS Terrain Tiles(terrarium)** — SRTM/NED 등 공개 표고 집합이며 고흥 일대에서
약 31.5 m/px다. 국토지리정보원 수치표고모델(5 m)이 목표지만 다운로드가 로그인과 대용량
전송 에이전트를 요구해 자동화되지 않는다. 그것이 도착하면 `--tier`의 `step`만 바꾸면 된다
— 팩 포맷은 그대로다. **출처는 팩 헤더에 실려 화면 캡션까지 간다.**
