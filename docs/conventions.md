# 규약 (Conventions) — v0.1

> 도메인 문서(01) §6의 [TBD] 규약을 Phase 0에서 확정한 것. 전 모듈이 이 문서와 그 구현체
> `engine/claw/common/`만 참조한다. 인라인 환산계수·규약 재정의 금지.
> 상태 표기: **[확정]** / **[기본값]** (공력 DB·기체 실데이터 대조 시 재검토) / **[TBD]**

## 1. 좌표계

- **[확정]** 항법 프레임: 국지 **NED** (North-East-Down). 원점 = 발사점 **[기본값]**. WGS-84 측지 변환은 env 모듈(M4) 소관
- **[확정]** 동체축: **FRD** — x 전방, y 우측(우현), z 하방. 원점 = 현재 CG
- **[확정]** 회전 부호: 오른손 법칙. 각속도 p(롤, x축), q(피치, y축), r(요, z축) — 동체축 성분

## 2. 자세 표현

- **[확정]** 쿼터니언: **scalar-first (w, x, y, z)**, Hamilton 규약, 단위 노름
- **[확정]** 의미: `q_nb` = NED→동체 회전. `v_b = C_bn(q_nb) · v_n`
- **[확정]** 오일러각: **3-2-1** (요 ψ → 피치 θ → 롤 φ). 특이점 θ = ±90°
- **[확정]** 내부 상태 정본은 쿼터니언 — 오일러각은 표시·입출력용

## 3. 단위계

- **[확정]** 내부 계산: **SI + rad** (m, m/s, kg, N, rad, rad/s, s)
- **[확정]** 경계(파일 입출력·UI 표시)에서만 deg/ft/kt 허용. 변환은 `claw.common.units`만 사용
- **[기본값]** 파일의 각도 표기: deg (사람 편집 친화) — 로드 시 rad 변환

## 4. 바람각

- **[확정]** V = |공기속도 동체 성분|, α = atan2(w, u), β = asin(v/V)

## 5. 조종입력 부호

- **[기본값]** 타면 변위 양(+) = 뒷전 내림(TE down). 러더는 TE left
- **[기본값]** 엘레본 믹싱: collective δe = 4면 평균(피치), differential δa = (좌 − 우)/2 (롤) — 4면 배치 확정 시 재정의 (도메인 문서 §2.2 TBD)
- **[확정]** 발생 모멘트의 부호는 **공력 DB가 정의** — 코드는 모멘트 부호를 가정하지 않는다
- **[확정]** 스로틀: 0~1 정규화, [좌, 우] 독립

## 6. 공력계수

- **[확정]** 기준량 S_ref, 세로 기준길이 c̄(MAC), 횡 기준길이 b — 파라미터 계층에 단일 정의
- **[확정]** 모멘트 기준점: DB 메타데이터에 명시, 코어가 현재 CG 기준으로 이전 변환
- **[기본값]** 계수 축: 동체축 — DB 메타데이터에 명시 필수

## 7. 시간·이산화

- **[확정]** t = 0 시뮬 시작, 초 단위. 주기 파라미터는 Hz 표기, 내부에서 dt(s) 변환 (샘플레이트 파라미터화 원칙, 구현 문서 §2.3)

## 8. 명명

- **[확정]** 코드 변수: snake_case. 프레임 접미사 `_n`(NED) / `_b`(동체) — 예: `vel_b`, `omega_b`, `pos_n`
- **[확정]** 파라미터 이름: 점 네임스페이스 `모듈.그룹.이름` — 예: `vehicle.mass.m0`, `fcl.scas.pitch.kp`
